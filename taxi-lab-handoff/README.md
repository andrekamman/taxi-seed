# taxi-lab handoff

This directory holds the k6 SQL load-testing design spec and implementation
plan, staged for migration to the separate `taxi-lab` repo. The k6 load
tester (`k6-loadtest`) has been removed from taxi-seed.

These files are intentionally kept **outside** `docs/` and are not part of
the published mkdocs site — they're working notes for whoever bootstraps
`taxi-lab`, not reference material for taxi-seed users.
